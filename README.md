# Omarchy Chicago Dark

Chicago at night in 1930s charcoal, rail green, and electric light.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-chicago-dark.git`, then run `omarchy theme set chicago-dark`.

For the companion theme, see [Omarchy Chicago Light](https://github.com/jacob-vincent-mink/omarchy-chicago-light).
