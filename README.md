# Omarchy Chicago Dark

A dark Omarchy theme for Chicago after dark: a 1930s skyline, the lit Wrigley Building, and Buckingham Fountain. Deep rail green and soft electric light carry the palette.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-chicago-dark.git`, then run `omarchy theme set chicago-dark`. Cycle the four wallpapers with `omarchy theme bg next`.

For the companion theme, see [Omarchy Chicago Light](https://github.com/jacob-vincent-mink/omarchy-chicago-light).
